# Funnel Analysis & Conversion Rate

## Project Overview

This project analyzes event-level data from a signup and checkout funnel. The objective is to measure unique users reaching each funnel stage, calculate stage-to-stage conversion rates, identify drop-offs, and determine the largest funnel leak.

## Funnel Stages

1. Visited Site
2. Signup Started
3. Details Filled
4. Email Verified
5. Purchase Completed

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Finding

The largest drop-off occurs between **Signup Started** and **Details Filled**.



- Users lost: **54**
- Conversion rate: **64.00%**

## Business Recommendation

The product team should investigate friction in the details form, including form length, required fields, validation errors, unclear instructions, and technical issues. Simplifying the form and improving user guidance could help improve conversion.
